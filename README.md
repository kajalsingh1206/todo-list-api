# To-Do List REST API

A RESTful To-Do List API built using Node.js, Express.js, and MongoDB Atlas.

## Features

- Create a new task
- Get all tasks
- Update an existing task
- Delete a task
- Store tasks in MongoDB Atlas
- REST API architecture
- JSON request and response format
- CORS enabled

## Technologies Used

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Postman
- JavaScript
- dotenv
- CORS
